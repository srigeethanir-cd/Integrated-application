# CD-SE Accelerators — Dashboard Frontend

> **Note on Dashboard Location**:
> The primary, production-ready React 18 + TypeScript + Vite + Tailwind CSS Story Explorer & Control Dashboard is located inside `cd-se-accelerators/backend/ui_dashboard/`.

## Running the Dashboard

To run the interactive React Dashboard UI:

```bash
cd ../backend/ui_dashboard
npm install
npm run dev
```

The UI dashboard will start on `http://localhost:5173` and automatically communicate with the FastAPI backend on `http://localhost:8000`.
